# Known limitations

- This is a broad playable alpha, not a content-complete release matching every acceptance criterion.
- Bosses currently share the target-field collision model; bespoke phases are not yet complete.
- Arena modifiers are named in stage data but several do not yet alter physics.
- Element descriptions and synergy selection exist; all secondary damage/status mechanics are not yet wired into combat.
- Upgrade/shop breadth, multiball, audio, and complete gamepad menu navigation need additional implementation.
- No real iPhone or Steam Deck hardware testing has been performed.
